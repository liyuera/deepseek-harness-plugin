风格 B · 流程泳道 状态可视化 · 引导式推进

  • 视觉：浅色卡片 + 阶段色条；「人在等你」的泳道高亮（琥珀色背景），AI 运行中用脉冲点。
  • 信息架构：横向泳道对应真实状态机；窄栏自动降级为「阶段分组 + 卡片流」，不丢信息。
  • 交互增强：卡片可拖拽推进（宿主状态机二次校验，非法即回弹并提示原因）、WIP 上限提示、底部详情抽屉不遮挡泳道。
  • 人性化：每张卡写明「卡在哪/等谁/等了多久/下一步会怎样」；进度步骤条让新手知道自己在第几步。
  • 宽屏：7 条泳道全览，横向滚动 + 底部抽屉；适合站会/评审投屏。
  • 风险：泳道宽度多（12 状态）→ 需要合并展示（如「交付中」聚合 submitting/mr_open），需在实现时定义泳道映射。
  • 实现量：中偏高（拖拽 + 抽屉 + 泳道映射）；窄栏与宽栏两套布局。
  • 适合：需要向团队解释流程、喜欢「一眼看全局」的用户。
