风格 A · 指挥台 高效率 · 键盘优先

  • 视觉：深色底 + 青色状态光，信息密度最高；左侧 3px 状态轨替代大色块，扫描成本低。
  • 信息架构：列表按「需要你 / AI 处理中 / 等待外部」自动分组，每行直接给出下一步动作与耗时。
  • 交互增强：⌘K 命令面板、J/K 切换、⏎ 执行下一步、⌘J 跳到下一张待办、操作可撤销 Toast。
  • 人性化：「它等了多久」「它卡在哪」直接写在行内；批处理入口在需要你时出现。
  • 宽屏：三栏（队列 / 详情 / 活动流），AI 活动与时间线常驻，不用来回切页面。
  • 风险：深色在 DSH 浅色主题下需要主题适配；信息密度高，新用户需要 1 次引导。
  • 实现量：中（新增命令面板 + 分组逻辑 + 快捷键层；不改状态机与接口）。
  • 适合：每天处理 10+ 工单、追求速度的重度用户。
