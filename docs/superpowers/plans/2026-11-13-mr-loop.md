# MR 评审闭环插件（mr-loop）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `mr-loop/` 下交付一个 host-only 的 DSH 插件：`/mr <url>` 绑定一个已有 MR 后，插件盯住它的评审与三套门禁，按 head sha 绑定轮次，用 `agent.followup` 在「新一轮评审出结论」时唤醒主代理，绝不用 `sleep`；修由主代理做，豁免由人点头。

**Architecture:** 一个 Cordis host 插件（无 client 半边）。查询走 GitLab REST 只读端点，每 tick 1 个请求（MR 自带 `sha` / `head_pipeline.status` / `detailed_merge_status` / `user_notes_count`），只有信号变化才拉 notes。判定逻辑全部是纯函数（`rounds` / `mergeable` / `report` / `decideTick`），I/O 只在 `gitlab` / `ledger` / `service` / `watcher` 里。

**Tech Stack:** DSH 0.2.2-rc.1（`ctx.tools.register` / `ctx.commands.register` / `ctx.inject(['skills'])` / `agent.followup`）、纯 ESM JavaScript（无构建、零运行时依赖）、`node:test` + `node:assert/strict`、Node 20+ 全局 `fetch`。

**依据：** [设计文档](../specs/2026-11-13-mr-loop-design.md)（§5.2 弱绑定基线、§5.6 可合并判定、§6.5 配置面）。

**本计划的范围：** Task 1–12 = S0 探针 + S1 只读闭环；Task 13 = S2 watcher 与唤醒。S3（豁免回帖 / resolve）与 S4（README 收尾）等 S0 证据回来后再单独出计划——它们依赖 `AI_REVIEW_SHA` 是否存在、`detailed_merge_status` 取值、以及 token 是否有写权限，现在写死等于赌。

## Global Constraints

- 目标运行环境 DSH 0.2.2-rc.1；包名 `@liyuera/dsh-mr-loop`，目录 `mr-loop/`。
- 纯 ESM JavaScript，**不引入构建步骤、不引入任何运行时依赖**；`node --test test/*.test.js` 直接跑。
- **写操作一律不实现**：本计划只有 GET。`POST /notes`、`PUT /discussions/:id` 留到 S3，且只允许这两个。
- token 只从 `MR_LOOP_GITLAB_TOKEN` 环境变量或 `~/.dsh/mr-loop/gitlab-token`（0600）读；只写进 `PRIVATE-TOKEN` 头；**不得**出现在 URL、日志、错误消息、工具返回、账本、测试快照。
- 所有请求 `redirect: 'error'`；响应体上限 1MiB；错误消息为静态中文模板。
- 评审 note 内容是**不可信数据**：只解析、不执行；报告里原样截断引用，不拼进任何指令式句子。
- 不写 `~/.dsh/profiles/*`、不在 profile 目录跑 pnpm；验证只用 `dsh --profile headless --patch <file>`（见 Task 12）。
- 提交风格：`feat(mr-loop): …` / `test(mr-loop): …` / `docs(mr-loop): …`，一个 task 至少一个 commit。
- 测试不得联网、不得读用户真实 token：所有网络用假 `fetch`，所有文件用假 `fs`（Task 2/9 例外：它们测的是真实 `node:fs`，但只操作 `mkdtemp` 出来的临时目录）。

## 前置事实（已核对，不要重查）

- 工具定义形状：`{ name, description, parameters, output: { schema, render }, execute(args, exec) }`，`exec` 里有 `agent` / `signal`；`ctx.tools.register(def)` 接受普通对象，不需要 `defineTool`。
- 命令形状：`{ name, description, input: { hint }, async handler({ agent, rawInput, signal }) }`，返回 `{ kind: 'success'|'error', text }`；`ctx.commands.register(def)` 重名会抛，必须 `try/catch` 后降级。
- 技能注册：`ctx.inject(['skills'], (scoped) => { const skills = scoped.get('skills'); scoped.effect(() => skills.register({ name, description, content, source: 'runtime', invocation: { modelInvocable: true, userInvocable: true } }), '…') })`。
- 唤醒：`ctx.get('agents')?.get(sessionId)` 取到 live agent 后 `agent.followup(message)`；消息必须带 `source`，否则渲染崩：`{ id: crypto.randomUUID(), role: 'user', source: { kind: 'plugin:mr-loop' }, content: [{ type: 'text', text }] }`。
- 判断「用户说过话」：`ctx.on('session/event', (session, event) => …)`，条件是 `event.type === 'user/message' && event.data?.source?.kind === 'user'`。
- 会话销毁：`ctx.on('session/disposed', (session) => …)`；插件卸载：`ctx.effect(() => () => { … })`。
- GitLab MR 对象字段：`iid` / `sha` / `state` / `draft` / `has_conflicts` / `detailed_merge_status` / `merge_status` / `head_pipeline: { id, sha, status, created_at }` / `user_notes_count` / `source_branch` / `target_branch` / `web_url`。
- 评审 note 模板（fixtures 已固化在 `bug-workflow/scripts/fixtures/`）：`## AI Code Review (src -> target)`、`结论: **可直接合并**`、`### 需要关注的问题` / `### 历史未收敛问题`、每条 `**文件**:` / `FID:` / `复验次数:` / `级别:` / `门禁分类:` / `位置:` / `问题:` / `建议:`，末尾 `> 备注：以下隐藏数据仅用于统计…` + `<!-- AI_REVIEW_SHA … -->` 等隐藏注释。

```js
// mr-loop/src/host/config.js
/**
 * 配置解析：纯函数，无 I/O。所有键都有默认值，未知键忽略（bundle patch 可能带别的字段）。
 * 数值键一律整数且不低于下限，非法值立刻抛 ConfigError，不做静默纠正。
 */
export class ConfigError extends Error {
  constructor(key, reason) {
    super(`配置项 ${key} ${reason}`)
    this.name = 'ConfigError'
    this.code = 'invalid-config'
  }
}

const DEFAULTS = Object.freeze({
  enabled: true,
  baseUrl: 'https://git.htwisdom.cn',
  tokenFile: '~/.dsh/mr-loop/gitlab-token',
  ledgerDir: '~/.dsh/mr-loop/ledger',
  pollWatchingMs: 60000,
  pollAwaitingMs: 10000,
  pollSettleMs: 15000,
  pollNoPipelineMs: 20000,
  roundTimeoutMs: 900000,
  gateSettleMs: 180000,
  maxRounds: 0,
  stallRounds: 3,
  reverifyStreak: 3,
  wallClockMs: 43200000,
  idleStopMs: 1800000,
  requestTimeoutMs: 15000,
  reviewMarker: 'AI Code Review',
  reviewTitlePrefix: 'AI Code Review (',
  sensitiveTitle: 'Sensitive Content Gate',
  mandatoryTitle: '必过项完整性检查',
  ledgerKeepRounds: 50,
})

/** 数值键 → 允许的最小值。`maxRounds` 例外：0 表示不限。 */
const MIN = Object.freeze({
  pollWatchingMs: 5000,
  pollAwaitingMs: 5000,
  pollSettleMs: 5000,
  pollNoPipelineMs: 5000,
  roundTimeoutMs: 60000,
  gateSettleMs: 30000,
  stallRounds: 1,
  reverifyStreak: 1,
  wallClockMs: 60000,
  idleStopMs: 60000,
  requestTimeoutMs: 1000,
  ledgerKeepRounds: 1,
})

const STRING_KEYS = Object.freeze([
  'tokenFile', 'ledgerDir', 'reviewMarker', 'reviewTitlePrefix', 'sensitiveTitle', 'mandatoryTitle',
])

function normalizeBaseUrl(raw) {
  let url
  try {
    url = new URL(raw)
  } catch {
    throw new ConfigError('baseUrl', '不是合法 URL')
  }
  if (url.protocol !== 'http:' && url.protocol !== 'https:') throw new ConfigError('baseUrl', '只支持 http 或 https')
  if (url.username || url.password) throw new ConfigError('baseUrl', '不能包含用户名或密码')
  if (url.search) throw new ConfigError('baseUrl', '不能包含查询参数')
  if (url.hash) throw new ConfigError('baseUrl', '不能包含片段')
  const pathname = url.pathname.replace(/\/+$/, '')
  return `${url.origin}${pathname}`
}

function positiveInt(value, key, min) {
  if (!Number.isSafeInteger(value) || value < min) throw new ConfigError(key, `必须是不小于 ${min} 的整数`)
  return value
}

/**
 * @param {Record<string, unknown>} [raw] bundle patch 里的 config 行
 * @returns {Readonly<typeof DEFAULTS>}
 */
export function resolveConfig(raw = {}) {
  const input = raw !== null && typeof raw === 'object' ? raw : {}
  const cfg = { ...DEFAULTS }

  if (input.enabled !== undefined) cfg.enabled = input.enabled !== false
  if (input.baseUrl !== undefined) {
    if (typeof input.baseUrl !== 'string' || input.baseUrl.trim() === '') throw new ConfigError('baseUrl', '不能为空')
    cfg.baseUrl = normalizeBaseUrl(input.baseUrl.trim())
  }
  for (const key of STRING_KEYS) {
    if (input[key] === undefined) continue
    if (typeof input[key] !== 'string' || input[key].trim() === '') throw new ConfigError(key, '不能为空')
    cfg[key] = input[key].trim()
  }
  if (input.maxRounds !== undefined) cfg.maxRounds = positiveInt(input.maxRounds, 'maxRounds', 0)
  for (const [key, min] of Object.entries(MIN)) {
    if (input[key] !== undefined) cfg[key] = positiveInt(input[key], key, min)
  }
  return Object.freeze(cfg)
}
```

```js
// mr-loop/src/host/token.js
/**
 * GitLab token 读取：环境变量优先，其次 0600 文件。
 * token 只在返回值的 `token` 字段里出现一次，不进日志、不进错误消息。
 * 文件权限比 0600 宽只给 warning（不阻断）——macOS 上 iCloud/共享目录常见。
 */
import { readFile as nodeReadFile, stat as nodeStat } from 'node:fs/promises'
import { homedir } from 'node:os'
import { resolve as resolvePath } from 'node:path'

export const TOKEN_ENV = 'MR_LOOP_GITLAB_TOKEN'
const MAX_TOKEN_LENGTH = 8192

export class TokenError extends Error {
  constructor(code, message) {
    super(message)
    this.name = 'TokenError'
    this.code = code
  }
}

/** `~/x` → `<home>/x`；绝对路径原样返回。 */
export function expandHome(input) {
  if (typeof input !== 'string' || input === '') return input
  if (input === '~') return homedir()
  if (input.startsWith('~/')) return resolvePath(homedir(), input.slice(2))
  return input
}

/**
 * @param {{ tokenFile: string, env?: Record<string, string|undefined>, readFileImpl?: typeof readFileImpl, statImpl?: typeof statImpl }} options
 * @returns {Promise<{ token: string, source: 'env'|'file', warning?: string }>}
 */
export async function readToken({ tokenFile, env = process.env, readFileImpl = nodeReadFile, statImpl = nodeStat }) {
  const fromEnv = String(env?.[TOKEN_ENV] ?? '').trim()
  if (fromEnv) return { token: fromEnv, source: 'env' }

  const file = expandHome(tokenFile)
  let info
  try {
    info = await statImpl(file)
  } catch {
    throw new TokenError('no-token', `未配置 GitLab token：${file} 不存在`)
  }
  if (!info.isFile()) throw new TokenError('no-token', `GitLab token 路径不是文件：${file}`)

  const warning = (info.mode & 0o077) !== 0 ? `token 文件权限过宽（建议 chmod 600）：${file}` : undefined
  const text = await readFileImpl(file, 'utf8')
  const token = String(text).trim()
  if (!token) throw new TokenError('no-token', `GitLab token 文件为空：${file}`)
  if (token.length > MAX_TOKEN_LENGTH) throw new TokenError('no-token', `GitLab token 过长：${file}`)
  return warning === undefined ? { token, source: 'file' } : { token, source: 'file', warning }
}
```

```js
// mr-loop/src/host/gitlab.js
/**
 * GitLab REST 只读客户端。只允许 4 个 GET，没有任何写路径：
 *   GET /projects/:p/merge_requests/:iid
 *   GET /projects/:p/merge_requests/:iid/notes?sort=desc&order_by=created_at&per_page=50
 *   GET /projects/:p/merge_requests/:iid/discussions?per_page=50
 *   GET /projects/:p/merge_requests/:iid/pipelines?per_page=1
 *
 * 安全不变量：token 只进 PRIVATE-TOKEN 头；redirect:'error' 防转发到别的主机；
 * 响应体上限 1MiB；错误消息是静态模板，不含 token / URL / 上游原文。
 * 纯依赖注入（fetchImpl / tokenProvider），可直接单测。
 */
const API_PREFIX = '/api/v4'
const AUTH_HEADER = 'PRIVATE-TOKEN'
export const MAX_RESPONSE_BYTES = 1024 * 1024
const MAX_PROJECT_SEGMENTS = 20
const MAX_PROJECT_LENGTH = 1024
const SEGMENT_RE = /^[A-Za-z0-9._-]+$/

const MESSAGE = Object.freeze({
  'no-token': '未配置 GitLab token',
  unauthorized: 'GitLab 鉴权失败，请检查 token',
  forbidden: 'GitLab 拒绝访问，token 权限不足',
  'not-found': 'GitLab 项目或 MR 不存在',
  conflict: 'GitLab 请求冲突，资源状态已变化',
  'rate-limited': 'GitLab 请求过于频繁，请稍后重试',
  network: '无法连接 GitLab 或服务暂时不可用',
  timeout: 'GitLab 请求超时',
  'bad-response': 'GitLab 响应结构异常',
  'invalid-project': 'GitLab 项目路径不合法（应形如 group/project）',
  'invalid-merge-request': 'GitLab MR 参数不合法',
})

export class GitlabError extends Error {
  constructor(code, status) {
    super(MESSAGE[code] ?? MESSAGE['bad-response'])
    this.name = 'GitlabError'
    this.code = code
    if (status !== undefined) this.status = status
  }
}

/** `group/sub/proj` → 单段编码；拒绝空段、`.`、`..` 与超长路径。 */
export function encodeProject(project) {
  if (typeof project !== 'string' || project.length === 0 || project.length > MAX_PROJECT_LENGTH) {
    throw new GitlabError('invalid-project')
  }
  const segments = project.split('/')
  if (segments.length < 2 || segments.length > MAX_PROJECT_SEGMENTS) throw new GitlabError('invalid-project')
  for (const segment of segments) {
    if (!SEGMENT_RE.test(segment) || segment === '.' || segment === '..') throw new GitlabError('invalid-project')
  }
  return encodeURIComponent(project)
}

function assertIid(iid) {
  if (!Number.isSafeInteger(iid) || iid <= 0) throw new GitlabError('invalid-merge-request')
}

function statusToCode(status) {
  if (status === 401) return 'unauthorized'
  if (status === 403) return 'forbidden'
  if (status === 404) return 'not-found'
  if (status === 409) return 'conflict'
  if (status === 429) return 'rate-limited'
  if (status >= 500) return 'network'
  return 'bad-response'
}

/**
 * @param {{ baseUrl: string, tokenProvider: () => (string|Promise<string>), fetchImpl?: typeof fetch, timeoutMs?: number }} options
 */
export function createGitlabClient({ baseUrl, tokenProvider, fetchImpl = globalThis.fetch, timeoutMs = 15000 }) {
  if (typeof tokenProvider !== 'function') throw new TypeError('tokenProvider must be a function')
  if (typeof fetchImpl !== 'function') throw new TypeError('fetchImpl must be a function')
  const base = baseUrl.replace(/\/+$/, '')

  async function request({ path, query, signal }) {
    let token = ''
    try {
      token = String((await tokenProvider()) ?? '').trim()
    } catch {
      token = ''
    }
    if (!token) throw new GitlabError('no-token')

    const url = new URL(`${base}${API_PREFIX}${path}`)
    if (query) for (const [key, value] of Object.entries(query)) url.searchParams.set(key, String(value))

    const controller = new AbortController()
    const forward = () => controller.abort(signal?.reason)
    if (signal) {
      if (signal.aborted) forward()
      else signal.addEventListener('abort', forward, { once: true })
    }
    const timer = setTimeout(() => controller.abort(new Error('timeout')), timeoutMs)

    let response
    try {
      response = await fetchImpl(url, {
        method: 'GET',
        headers: { [AUTH_HEADER]: token, accept: 'application/json' },
        redirect: 'error',
        signal: controller.signal,
      })
    } catch (error) {
      if (signal?.aborted) throw new GitlabError('timeout', undefined)
      if (error?.name === 'AbortError' || controller.signal.aborted) throw new GitlabError('timeout')
      throw new GitlabError('network')
    } finally {
      clearTimeout(timer)
      if (signal) signal.removeEventListener?.('abort', forward)
    }

    if (!response.ok) throw new GitlabError(statusToCode(response.status), response.status)

    let text
    try {
      text = await response.text()
    } catch {
      throw new GitlabError('bad-response')
    }
    if (Buffer.byteLength(text, 'utf8') > MAX_RESPONSE_BYTES) throw new GitlabError('bad-response')
    try {
      return JSON.parse(text)
    } catch {
      throw new GitlabError('bad-response')
    }
  }

  const mrPath = (project, iid) => {
    assertIid(iid)
    return `/projects/${encodeProject(project)}/merge_requests/${iid}`
  }

  return {
    async getMergeRequest({ project, iid, signal }) {
      const data = await request({ path: mrPath(project, iid), signal })
      if (data === null || typeof data !== 'object' || Number.isSafeInteger(data.iid) === false || typeof data.sha !== 'string') {
        throw new GitlabError('bad-response')
      }
      return data
    },
    async listNotes({ project, iid, signal }) {
      const data = await request({
        path: `${mrPath(project, iid)}/notes`,
        query: { sort: 'desc', order_by: 'created_at', per_page: 50 },
        signal,
      })
      if (!Array.isArray(data)) throw new GitlabError('bad-response')
      return data.filter((note) => note !== null && typeof note === 'object')
    },
    async listDiscussions({ project, iid, signal }) {
      const data = await request({ path: `${mrPath(project, iid)}/discussions`, query: { per_page: 50 }, signal })
      if (!Array.isArray(data)) throw new GitlabError('bad-response')
      return data.filter((item) => item !== null && typeof item === 'object')
    },
    async listPipelines({ project, iid, signal }) {
      const data = await request({ path: `${mrPath(project, iid)}/pipelines`, query: { per_page: 1 }, signal })
      if (!Array.isArray(data)) throw new GitlabError('bad-response')
      return data.filter((item) => item !== null && typeof item === 'object')
    },
  }
}
```

```js
import { mkdir, writeFile } from 'node:fs/promises'
import { dirname, resolve } from 'node:path'
import { fileURLToPath } from 'node:url'
import { resolveConfig } from '../src/host/config.js'
import { readToken } from '../src/host/token.js'
import { createGitlabClient } from '../src/host/gitlab.js'

const HERE = dirname(fileURLToPath(import.meta.url))

function parseMrUrl(input, baseUrl) {
  const url = new URL(input)
  if (`${url.origin}${url.pathname}`.startsWith(baseUrl) === false && !url.href.startsWith(baseUrl)) {
    throw new Error(`MR 地址不属于 baseUrl（${baseUrl}）`)
  }
  const match = /^\/(.+?)\/-\/merge_requests\/(\d+)\/?$/.exec(url.pathname)
  if (!match) throw new Error('MR 地址格式应为 https://<host>/<group>/<project>/-/merge_requests/<iid>')
  return { project: match[1], iid: Number(match[2]) }
}

function markersOf(body) {
  return [...String(body ?? '').matchAll(/<!--\s*(AI_REVIEW_[A-Z_]+)\s*([^>]*)-->/g)].map((m) => ({
    name: m[1],
    value: m[2].trim().slice(0, 80),
  }))
}

function summarizeNote(note) {
  return {
    id: note.id,
    author: note.author?.username ?? null,
    createdAt: note.created_at,
    system: note.system === true,
    firstLine: String(note.body ?? '').split('\n').find((line) => line.trim() !== '') ?? '',
    markers: markersOf(note.body),
    bodyLength: String(note.body ?? '').length,
  }
}

async function main() {
  const cfg = resolveConfig({})
  const target = process.argv[2]
  if (!target) {
    console.error('用法：node mr-loop/scripts/spike.mjs <MR URL>')
    process.exit(2)
  }
  const { project, iid } = parseMrUrl(target, cfg.baseUrl)
  const { token, source, warning } = await readToken({ tokenFile: cfg.tokenFile })
  const client = createGitlabClient({ baseUrl: cfg.baseUrl, tokenProvider: () => token, timeoutMs: cfg.requestTimeoutMs })

  const [mr, notes, discussions, pipelines] = await Promise.all([
    client.getMergeRequest({ project, iid }),
    client.listNotes({ project, iid }),
    client.listDiscussions({ project, iid }),
    client.listPipelines({ project, iid }),
  ])

  const me = await fetch(`${cfg.baseUrl}/api/v4/personal_access_tokens/self`, {
    headers: { 'PRIVATE-TOKEN': token, accept: 'application/json' },
    redirect: 'error',
  }).then((res) => (res.ok ? res.json() : { error: res.status })).catch(() => ({ error: 'network' }))

  const reviewNotes = notes.filter((note) => /AI Code Review/.test(String(note.body ?? '')))
  const evidence = {
    capturedAt: new Date().toISOString(),
    tokenSource: source,
    tokenWarning: warning ?? null,
    tokenScopes: Array.isArray(me.scopes) ? me.scopes : me,
    project,
    iid,
    mr: {
      sha: mr.sha,
      state: mr.state,
      draft: mr.draft,
      hasConflicts: mr.has_conflicts,
      detailedMergeStatus: mr.detailed_merge_status ?? null,
      mergeStatus: mr.merge_status ?? null,
      userNotesCount: mr.user_notes_count,
      sourceBranch: mr.source_branch,
      targetBranch: mr.target_branch,
      headPipeline: mr.head_pipeline ?? null,
    },
    pipelines,
    notes: notes.map(summarizeNote),
    reviewNotes: reviewNotes.map(summarizeNote),
    discussions: discussions.map((discussion) => ({
      id: discussion.id,
      resolvable: discussion.notes?.some((note) => note.resolvable === true) ?? false,
      resolved: discussion.notes?.every((note) => note.resolvable === false || note.resolved === true) ?? null,
      notes: (discussion.notes ?? []).map((note) => ({ id: note.id, resolvable: note.resolvable, resolved: note.resolved, system: note.system })),
    })),
    checks: {
      hasAiReviewShaMarker: notes.some((note) => markersOf(note.body).some((m) => m.name === 'AI_REVIEW_SHA')),
      hasDetailedMergeStatus: typeof mr.detailed_merge_status === 'string',
      hasHeadPipeline: mr.head_pipeline !== null && mr.head_pipeline !== undefined,
      userNotesCountMatches: mr.user_notes_count === notes.filter((note) => note.system !== true).length,
    },
  }

  const outDir = resolve(HERE, '..', '.tmp')
  await mkdir(outDir, { recursive: true })
  const outFile = resolve(outDir, `spike-${iid}.json`)
  await writeFile(outFile, `${JSON.stringify(evidence, null, 2)}\n`, 'utf8')
  console.log(`证据已写入 ${outFile}`)
  console.log(JSON.stringify(evidence.checks, null, 2))
}

main().catch((error) => {
  console.error(`探针失败：${error.message}`)
  process.exitCode = 1
})
```

```js
// mr-loop/src/host/parse-gates.js
/**
 * 两类门禁 note 的解析。只认自己的模板；任何认不出的形状返回 unknown，
 * 由调用方按 fail-closed 处理（unknown ≠ pass）。
 * raw 保留原文前 200 字，供报告取证，不参与任何判定。
 */
const RAW_LIMIT = 200

const verdictOf = (body, passText, blockText) => {
  const match = /^\s*(?:\*\*)?结论(?:\*\*)?\s*[:：]\s*(.*)$/m.exec(body)
  if (!match) return 'unknown'
  const value = match[1].replace(/\*\*/g, '').trim()
  if (value.startsWith(passText)) return 'pass'
  if (value.startsWith(blockText)) return 'block'
  return 'unknown'
}

const numberAfter = (body, pattern) => {
  const match = pattern.exec(body)
  if (!match) return null
  const value = Number.parseInt(match[1], 10)
  return Number.isSafeInteger(value) ? value : null
}

const rawOf = (body) => String(body ?? '').trim().slice(0, RAW_LIMIT)

/**
 * @param {string} body GitLab note markdown
 * @returns {{ verdict: 'pass'|'block'|'unknown', total: number|null, waived: number|null, effective: number|null, blocking: number|null, raw: string }}
 */
export function parseSensitiveGate(body) {
  const text = String(body ?? '')
  const verdict = verdictOf(text, '门禁通过', '阻止合并')
  return {
    verdict,
    total: numberAfter(text, /共\s*(\d+)\s*条命中/),
    waived: numberAfter(text, /历史豁免\s*(\d+)\s*条/),
    effective: numberAfter(text, /当前有效\s*(\d+)\s*条/),
    blocking: numberAfter(text, /阻断项\s*[:：]\s*(\d+)\s*条/),
    raw: rawOf(text),
  }
}

const subItem = (body, label) => {
  const pattern = new RegExp(`${label}\\s*[:：]\\s*([^；;\\n]+)`)
  const match = pattern.exec(String(body ?? ''))
  return match ? match[1].replace(/\*\*/g, '').trim() : null
}

/**
 * @param {string} body GitLab note markdown
 * @returns {{ verdict: 'pass'|'block'|'unknown', items: { sensitive: string|null, review: string|null, evidence: string|null }, raw: string }}
 */
export function parseMandatoryGate(body) {
  const text = String(body ?? '')
  return {
    verdict: verdictOf(text, '通过', '阻止合并'),
    items: {
      sensitive: subItem(text, '敏感信息门禁'),
      review: subItem(text, 'AI 代码评审'),
      evidence: subItem(text, 'AI 评审证据检查'),
    },
    raw: rawOf(text),
  }
```

```js
// mr-loop/src/host/rounds.js
/**
 * 轮次归属：一条评审属于哪个 sha、哪一轮，只认证据（见设计 §5.2）。
 *   强绑定：note 里 <!-- AI_REVIEW_SHA ... --> 与当前 sha 相等（允许短 sha 前缀）
 *   弱绑定：无标记，但 created_at >= baselineAt（该 sha 的 head_pipeline.created_at，
 *          取不到时用本轮首次观测时间），且标题前缀匹配
 *   其余：stale，进 dropped[]，不参与任何判定
 * 纯函数：不碰网络、不碰时钟（baselineAt / observedAt 由调用方注入）。
 */
import { parseReview, isReviewBody } from './parse-review.js'
import { parseSensitiveGate, parseMandatoryGate } from './parse-gates.js'

const SHA_MARKER_RE = /<!--\s*AI_REVIEW_SHA\s+([0-9a-f]{7,64})\s*-->/i

/** 该 sha 的流水线创建时间，作为 push 时间的近似；缺失返回 0。 */
export function baselineOf(mr) {
  const createdAt = mr?.head_pipeline?.created_at
  const parsed = typeof createdAt === 'string' ? Date.parse(createdAt) : Number.NaN
  return Number.isFinite(parsed) ? parsed : 0
}

/** 从 note 正文提取 AI_REVIEW_SHA 标记值。 */
export function reviewShaOf(body) {
  const match = SHA_MARKER_RE.exec(String(body ?? ''))
  return match ? match[1].toLowerCase() : null
}

const shaMatches = (marker, sha) => {
  const target = String(sha ?? '').toLowerCase()
  return marker === target || target.startsWith(marker) || marker.startsWith(target)
}

/**
 * @returns {{ binding: 'strong'|'weak' } | { stale: true, reason: 'other-sha'|'before-baseline' }}
 */
export function classifyReviewNote({ note, sha, baselineAt, cfg }) {
  const marker = reviewShaOf(note?.body)
  if (marker) return shaMatches(marker, sha) ? { binding: 'strong' } : { stale: true, reason: 'other-sha' }
  const createdAt = Date.parse(note?.created_at ?? '')
  if (!Number.isFinite(createdAt)) return { stale: true, reason: 'before-baseline' }
  if (createdAt < (baselineAt ?? 0)) return { stale: true, reason: 'before-baseline' }
  const body = String(note?.body ?? '')
  if (!body.includes(cfg.reviewTitlePrefix)) return { stale: true, reason: 'before-baseline' }
  return { binding: 'weak' }
}

const isSensitiveNote = (body, cfg) => String(body ?? '').includes(cfg.sensitiveTitle)
const isMandatoryNote = (body, cfg) => String(body ?? '').includes(cfg.mandatoryTitle)

/** 同 sha 多条命中取 note.id 最大的一条。 */
const latestBy = (items) => items.reduce((best, item) => (best === null || item.note.id > best.note.id ? item : best), null)

/**
 * 把一次 notes 快照归并成一整轮。
 * @param {{ mr: object, notes: object[], cfg: object, observedAt: number }} input
 */
export function buildRound({ mr, notes, cfg, observedAt }) {
  const sha = mr.sha
  const baselineAt = baselineOf(mr) || observedAt || 0
  const dropped = []
  const reviewHits = []
  const sensitiveHits = []
  const mandatoryHits = []

  for (const note of notes ?? []) {
    if (!note || note.system === true) continue
    const body = String(note.body ?? '')

    if (isReviewBody(body)) {
      const verdict = classifyReviewNote({ note, sha, baselineAt, cfg })
      if (verdict.stale) {
        dropped.push({ noteId: note.id, reason: 'stale', detail: verdict.reason })
        continue
      }
      reviewHits.push({ note, binding: verdict.binding, parsed: parseReview(body) })
      continue
    }

    const createdAt = Date.parse(note.created_at ?? '')
    const fresh = Number.isFinite(createdAt) && createdAt >= baselineAt

    if (isSensitiveNote(body, cfg)) {
      if (!fresh) {
        dropped.push({ noteId: note.id, reason: 'stale', detail: 'before-baseline' })
        continue
      }
      sensitiveHits.push({ note, parsed: parseSensitiveGate(body) })
      continue
    }
    if (isMandatoryNote(body, cfg)) {
      if (!fresh) {
        dropped.push({ noteId: note.id, reason: 'stale', detail: 'before-baseline' })
        continue
      }
      mandatoryHits.push({ note, parsed: parseMandatoryGate(body) })
    }
  }

  const review = latestBy(reviewHits)
  const sensitive = latestBy(sensitiveHits)
  const mandatory = latestBy(mandatoryHits)

  return {
    sha,
    n: null,
    observedAt,
    baselineAt,
    binding: review?.binding ?? null,
    review: review === null ? null : {
      noteId: review.note.id,
      binding: review.binding,
      verdict: review.parsed.verdict,
      blocking: review.parsed.blocking,
      nonBlocking: review.parsed.nonBlocking,
      historicalUnresolved: countOf(review.note.body, /历史未收敛\s*[:：]\s*`?(\d+)/),
      verifiedFixed: countOf(review.note.body, /本轮已验证修复\s*[:：]\s*`?(\d+)/),
      jobDuration: durationOf(review.note.body),
    },
    sensitive: sensitive === null ? null : { noteId: sensitive.note.id, ...sensitive.parsed },
    mandatory: mandatory === null ? null : { noteId: mandatory.note.id, ...mandatory.parsed },
    dropped,
  }
}

function countOf(body, pattern) {
  const match = pattern.exec(String(body ?? ''))
  return match ? Number.parseInt(match[1], 10) : null
}

function durationOf(body) {
  const match = /Job耗时\s*:\s*`?([^`\n|]+)`?/.exec(String(body ?? ''))
  return match ? match[1].trim() : null
}
```

```js
// mr-loop/src/host/mergeable.js
/**
 * 可合并判定（设计 §5.6）。全部满足才算；缺哪项用中文写进 missing，报告直接展示。
 * 反模式：只盯 AI 评审。三套门禁 + GitLab 自己的详细合并态一起看，unknown 不当 pass。
 * 必过项是建议性的：只在有本轮结论时计入（它通常只在 MR 早期出现一次）。
 */
export function evaluateMergeable({ mr, round, decisions = {} }) {
  const missing = []
  let degraded = false

  if (mr?.state !== 'opened') missing.push(`MR 状态是 ${mr?.state ?? 'unknown'}`)
  if (mr?.draft === true) missing.push('MR 还是草稿')
  if (mr?.has_conflicts === true) missing.push('与目标分支有冲突')

  const verdict = round?.review?.verdict ?? 'unknown'
  if (verdict !== 'pass') missing.push(verdict === 'changes' ? 'AI 评审结论为需要修改' : 'AI 评审结论未知（未出或解析失败）')

  const blocking = Array.isArray(round?.review?.blocking) ? round.review.blocking : []
  const unresolved = blocking.filter((item) => {
    const decision = decisions?.[item?.fid]
    return decision === undefined || decision === null
  })
  if (unresolved.length > 0) missing.push(`有 ${unresolved.length} 条阻塞问题未处置`)

  const sensitive = round?.sensitive?.verdict ?? 'unknown'
  if (sensitive !== 'pass') missing.push(sensitive === 'block' ? '敏感内容门禁未通过' : '敏感内容门禁本轮无结论')

  if (round?.mandatory?.verdict === 'block') missing.push('必过项完整性检查未通过')

  if (typeof mr?.detailed_merge_status === 'string') {
    if (mr.detailed_merge_status !== 'mergeable') missing.push(`GitLab 合并态：${mr.detailed_merge_status}`)
  } else {
    degraded = true
    if (mr?.merge_status !== 'can_be_merged') missing.push(`GitLab 合并态：${mr?.merge_status ?? 'unknown'}`)
  }

  return { mergeable: missing.length === 0, missing, degraded }
}
```

```js
// mr-loop/src/host/ledger.js
/**
 * 账本：一个 MR 一个 JSON 文件，0600，原子写（tmp + rename），同文件写串行。
 * 不用 storageDomain 的原因见设计 ADR-5：免 peer 依赖、可人肉查看。
 * 读坏文件按「没有账本」处理，绝不抛给调用方。
 */
import { mkdir, readFile, rename, rm, writeFile } from 'node:fs/promises'
import { join } from 'node:path'
import { homedir } from 'node:os'
import { resolve as resolvePath } from 'node:path'

const MAX_DECISIONS = 200

export function expandHome(input) {
  if (typeof input !== 'string' || input === '') return input
  if (input === '~') return homedir()
  if (input.startsWith('~/')) return resolvePath(homedir(), input.slice(2))
  return input
}

const slug = (projectPath) => String(projectPath ?? '').trim().replace(/[^A-Za-z0-9._-]+/g, '-').replace(/^-+|-+$/g, '') || 'unknown'

/**
 * @param {{ dir: string, keepRounds?: number, keepDecisions?: number }} options
 */
export function createLedger({ dir, keepRounds = 50, keepDecisions = MAX_DECISIONS }) {
  const root = expandHome(dir)
  const queues = new Map()

  const pathOf = ({ projectPath, iid }) => join(root, `${slug(projectPath)}-${iid}.json`)

  const trim = (record) => {
    const rounds = Array.isArray(record.rounds) ? record.rounds : []
    const decisions = record.decisions !== null && typeof record.decisions === 'object' ? record.decisions : {}
    const entries = Object.entries(decisions).sort((a, b) => String(b[1]?.at ?? '').localeCompare(String(a[1]?.at ?? '')))
    const keptEntries = entries.slice(0, keepDecisions)
    const dropped = Math.max(0, rounds.length - keepRounds) + Math.max(0, entries.length - keptEntries.length)
    return {
      ...record,
      rounds: rounds.slice(-keepRounds),
      decisions: Object.fromEntries(keptEntries),
      ...(dropped > 0 ? { trimmed: dropped } : {}),
    }
  }

  const save = (record) => {
    const projectPath = record?.binding?.projectPath
    const iid = record?.binding?.iid
    const file = pathOf({ projectPath, iid })
    const payload = trim({ ...record, version: 1, updatedAt: record.updatedAt ?? new Date().toISOString() })
    const task = async () => {
      await mkdir(root, { recursive: true, mode: 0o700 })
      const tmpFile = `${file}.tmp-${process.pid}-${Math.random().toString(16).slice(2)}`
      await writeFile(tmpFile, `${JSON.stringify(payload, null, 2)}\n`, { encoding: 'utf8', mode: 0o600 })
      await rename(tmpFile, file)
      return payload
    }
    const previous = queues.get(file) ?? Promise.resolve()
    const next = previous.then(task, task)
    queues.set(file, next.catch(() => {}))
    return next
  }

  const load = async ({ projectPath, iid }) => {
    try {
      const text = await readFile(pathOf({ projectPath, iid }), 'utf8')
      const parsed = JSON.parse(text)
      return parsed !== null && typeof parsed === 'object' ? parsed : null
    } catch {
      return null
    }
  }

  const forget = async ({ projectPath, iid }) => {
    await rm(pathOf({ projectPath, iid }), { force: true })
  }

  return { pathOf, save, load, forget }
}
```

```js
// mr-loop/src/host/report.js
/**
 * 报告渲染：纯函数、固定形状。每轮长得一样，才好扫。
 * 只陈述事实（含 unknown 与取证片段），不写「请修复」这类指令——修不修由主代理判断。
 */
const OK = '✅'
const BAD = '⛔'
const PENDING = '⏳'
const WARN = '⚠️'

const pad = (label) => `${label.padEnd(5, ' ')}`
const ago = (now, iso) => {
  const time = Date.parse(iso ?? '')
  if (!Number.isFinite(time)) return ''
  const seconds = Math.max(0, Math.round((now - time) / 1000))
  return seconds < 60 ? `${seconds} 秒前` : `${Math.round(seconds / 60)} 分钟前`
}

const verdictLine = (review) => {
  if (review === null || review === undefined) return `${PENDING} 未出`
  if (review.verdict === 'pass') return `${OK} 可直接合并`
  if (review.verdict === 'changes') return `${BAD} 需要修改`
  return `${PENDING} 解析失败（unknown）`
}

/**
 * @param {{ binding: object, mr: object, round: object|null, decisions: object, mergeability: object, paused: object|null, now: number }} input
 * @returns {string}
 */
export function renderReport({ binding, mr, round, decisions = {}, mergeability, paused = null, now = Date.now() }) {
  const lines = []
  lines.push(`MR !${binding.iid} · ${binding.projectPath}`)
  const bindingLabel = round?.binding === 'strong' ? '强绑定' : round?.binding === 'weak' ? '弱绑定（无 SHA 证明）' : '无评审'
  lines.push(`${binding.sourceBranch} → ${binding.targetBranch} · 第 ${round?.n ?? 0} 轮 · sha ${String(mr.sha ?? '').slice(0, 8)}（${bindingLabel}）`)

  const review = round?.review ?? null
  const reviewTail = review === null
    ? ''
    : ` · 历史未收敛 ${review.historicalUnresolved ?? '?'} · 本轮已验证修复 ${review.verifiedFixed ?? '?'}${review.jobDuration ? ` · Job ${review.jobDuration}` : ''}`
  lines.push(`${pad('评审')}${verdictLine(review)}${reviewTail}`)

  const sensitive = round?.sensitive ?? null
  const sensitiveLine = sensitive === null
    ? `${PENDING} 未出`
    : sensitive.verdict === 'pass'
      ? `${OK} 门禁通过 · 共 ${sensitive.total ?? '?'} / 历史豁免 ${sensitive.waived ?? '?'} / 当前有效 ${sensitive.effective ?? '?'}`
      : sensitive.verdict === 'block'
        ? `${BAD} 阻止合并 · 有效 ${sensitive.effective ?? '?'} 条 / 阻断项 ${sensitive.blocking ?? '?'}`
        : `${PENDING} 解析失败（unknown）`
  lines.push(`${pad('敏感')}${sensitiveLine}`)

  const mandatory = round?.mandatory ?? null
  const mandatoryLine = mandatory === null
    ? `${PENDING} 无本轮结论`
    : mandatory.verdict === 'pass'
      ? `${OK} 通过`
      : mandatory.verdict === 'block'
        ? `${BAD} 阻止合并（敏感 ${mandatory.items?.sensitive ?? '?'} / 评审 ${mandatory.items?.review ?? '?'} / 证据 ${mandatory.items?.evidence ?? '?'}）`
        : `${PENDING} 解析失败（unknown）`
  lines.push(`${pad('必过')}${mandatoryLine}`)

  const blocking = Array.isArray(review?.blocking) ? review.blocking : []
  const openItems = blocking.filter((item) => decisions[item.fid] === undefined)
  lines.push(`${pad('阻塞')}${openItems.length === 0 ? '无' : openItems.map((item) => `#${item.fid} · ${item.level ?? '?'}`).join('；')}`)

  const pendingWaives = Object.values(decisions).filter((decision) => decision?.kind === 'waive' && decision?.noteId === undefined)
  lines.push(`${pad('待点头')}${pendingWaives.length === 0 ? '（无）' : `${pendingWaives.length} 条豁免草稿`}`)

  const mergeLine = mergeability.mergeable
    ? `${OK} 可合${mergeability.degraded ? `（${WARN} 降级判定）` : ''}`
    : `${BAD} 差 ${mergeability.missing.length} 项：${mergeability.missing.join('；')}`
  lines.push(`${pad('合并')}${mergeLine}`)

  if (paused !== null && paused !== undefined) {
    lines.push(`${pad('暂停')}${paused.reason}（${ago(now, paused.at)}）—— /mr resume 继续`)
  }

  return lines.join('\n')
}
```

```js
/** 只接受「与配置同源、同 base 路径前缀」的 MR 地址；其余一律 null，由调用方报 invalid-url。 */
export function parseMrUrl(input, baseUrl) {
  let url
  let base
  try {
    url = new URL(String(input ?? '').trim())
    base = new URL(baseUrl)
  } catch {
    return null
  }
  if (url.origin !== base.origin) return null
  const basePath = base.pathname.replace(/\/+$/, '')
  let pathname = url.pathname
  if (basePath) {
    if (!pathname.startsWith(`${basePath}/`)) return null
    pathname = pathname.slice(basePath.length)
  }
  const match = /^\/(.+)\/-\/merge_requests\/(\d+)\/?$/.exec(pathname)
  if (!match) return null
  const project = match[1].replace(/^\/+/, '')
  if (!project.includes('/') || project.includes('/-/')) return null
  const iid = Number(match[2])
  return Number.isSafeInteger(iid) && iid > 0 ? { project, iid } : null
}
```

```js
// mr-loop/src/host/repo.js
/**
 * 只为绑定校验存在的只读 git 读取：三条命令，绝不写仓库。
 * 依次取：仓库根 → origin → 当前分支。
 */
import { execFile } from 'node:child_process'
import { promisify } from 'node:util'

const run = promisify(execFile)

export class RepoError extends Error {
  constructor(code, message) {
    super(message)
    this.name = 'RepoError'
    this.code = code
  }
}

const stripGit = (value) => value.replace(/\/+$/, '').replace(/\.git$/, '')

/** https / ssh:// / scp 三种 remote 写法 → { host, path }。 */
export function parseRemote(remoteUrl) {
  const raw = String(remoteUrl ?? '').trim()
  if (!raw) return null
  if (/^https?:\/\//i.test(raw)) {
    try {
      const url = new URL(raw)
      const path = stripGit(url.pathname).replace(/^\/+/, '')
      return path.includes('/') ? { host: url.hostname.toLowerCase(), path } : null
    } catch {
      return null
    }
  }
  const scp = /^(?:ssh:\/\/)?(?:[^@/]+@)?([^:/]+)(?::\d+)?[:/](.+)$/.exec(raw)
  if (!scp) return null
  const path = stripGit(scp[2]).replace(/^\/+/, '')
  return path.includes('/') ? { host: scp[1].toLowerCase(), path } : null
}

async function defaultExec(args, cwd) {
  const { stdout } = await run('git', ['-C', cwd, ...args], { timeout: 5000, maxBuffer: 1024 * 1024 })
  return String(stdout).trim()
}

/**
 * @param {{ cwd?: string, exec?: (args: string[], cwd: string) => Promise<string> }} options
 */
export async function readRepoState({ cwd, exec = defaultExec }) {
  const workdir = typeof cwd === 'string' && cwd !== '' ? cwd : process.cwd()
  let root
  try {
    root = await exec(['rev-parse', '--show-toplevel'], workdir)
  } catch {
    throw new RepoError('not-a-repo', `当前目录不是 git 仓库：${workdir}`)
  }
  let remoteUrl
  try {
    remoteUrl = await exec(['remote', 'get-url', 'origin'], root)
  } catch {
    throw new RepoError('no-remote', `仓库没有 origin 远程：${root}`)
  }
  const parsed = parseRemote(remoteUrl)
  if (parsed === null) throw new RepoError('no-remote', `无法解析 origin 地址：${root}`)
  const branch = await exec(['rev-parse', '--abbrev-ref', 'HEAD'], root)
  return { root, remoteUrl, host: parsed.host, projectPath: parsed.path, branch }
}
```

```js
// mr-loop/src/host/service.js
/**
 * 绑定服务：唯一有状态的地方。纯判定（rounds / mergeable / report）都在别处，
 * 这里只做「取数 → 归并 → 落账本 → 出报告」的编排，错误一律 ServiceError(code)。
 */
import { parseMrUrl } from './url.js'
import { readRepoState } from './repo.js'
import { buildRound } from './rounds.js'
import { evaluateMergeable } from './mergeable.js'
import { renderReport } from './report.js'

export class ServiceError extends Error {
  constructor(code, message) {
    super(message)
    this.name = 'ServiceError'
    this.code = code
  }
}

const sameProject = (a, b) => String(a ?? '').toLowerCase() === String(b ?? '').toLowerCase()

const blockingKey = (round) => (round?.review?.blocking ?? []).map((item) => item.fid).sort().join(',')

/**
 * @param {{ config: object, ledger: object, gitlab: object, repoState?: Function, now?: () => number }} deps
 */
export function createService({ config, ledger, gitlab, repoState = readRepoState, now = Date.now, onBound = undefined }) {
  /** @type {Map<string, object>} sessionId → state */
  const bindings = new Map()

  function requireState(sessionId) {
    const state = bindings.get(sessionId)
    if (state === undefined) throw new ServiceError('not-bound', '当前会话还没有绑定 MR，先 /mr <链接>')
    return state
  }

  function report(state) {
    return renderReport({
      binding: state.binding,
      mr: state.mr,
      round: state.round,
      decisions: state.decisions,
      mergeability: state.mergeability,
      paused: state.paused,
      now: now(),
    })
  }

  async function persist(state, extra = {}) {
    await ledger.save({
      version: 1,
      binding: state.binding,
      rounds: state.rounds,
      decisions: state.decisions,
      mergeableAt: state.mergeableAt ?? null,
      terminal: state.terminal ?? null,
      paused: state.paused,
      updatedAt: new Date(now()).toISOString(),
      ...extra,
    })
  }

  async function bind({ sessionId, url, repoRoot }) {
    const parsed = parseMrUrl(url, config.baseUrl)
    if (parsed === null) throw new ServiceError('invalid-url', `MR 地址不属于 ${config.baseUrl} 或格式不对`)

    const mr = await gitlab.getMergeRequest({ project: parsed.project, iid: parsed.iid })
    if (mr.state !== 'opened') throw new ServiceError('mr-not-open', `MR 状态是 ${mr.state}`)

    let repo
    try {
      repo = await repoState({ cwd: repoRoot })
    } catch {
      throw new ServiceError('repo-mismatch', '当前目录不是可用的 git 仓库（需要可读的 origin）')
    }
    if (!sameProject(repo.projectPath, parsed.project)) {
      throw new ServiceError('repo-mismatch', `当前仓库是 ${repo.projectPath}，MR 属于 ${parsed.project}`)
    }

    const notes = await gitlab.listNotes({ project: parsed.project, iid: parsed.iid })
    const observedAt = now()
    const previous = await ledger.load({ projectPath: parsed.project, iid: parsed.iid })
    const n = (Array.isArray(previous?.rounds) ? previous.rounds.length : 0) + 1
    const round = { ...buildRound({ mr, notes, cfg: config, observedAt }), n }

    const state = {
      sessionId,
      binding: {
        projectPath: parsed.project,
        iid: parsed.iid,
        repoRoot: repo.root,
        sourceBranch: mr.source_branch,
        targetBranch: mr.target_branch,
        boundAt: new Date(observedAt).toISOString(),
      },
      mr,
      round,
      rounds: [...(Array.isArray(previous?.rounds) ? previous.rounds : []), round].slice(-config.ledgerKeepRounds),
      decisions: previous?.decisions !== null && typeof previous?.decisions === 'object' ? previous.decisions : {},
      mergeability: null,
      paused: null,
      notesCount: mr.user_notes_count ?? null,
      pipelineStatus: mr.head_pipeline?.status ?? null,
      startedAt: observedAt,
      lastProgressAt: observedAt,
      stallStreak: 0,
      reverifyStreak: 0,
      stallKey: blockingKey(round),
    }
    state.mergeability = evaluateMergeable({ mr, round, decisions: state.decisions })
    bindings.set(sessionId, state)
    await persist(state)

    const warnings = repo.branch !== mr.source_branch
      ? [{ code: 'branch-mismatch', message: `当前分支是 ${repo.branch}，MR 源分支是 ${mr.source_branch}` }]
      : []
    try {
      onBound?.({ sessionId, binding: state.binding })
    } catch {
      /* 启动 watcher 失败不影响绑定本身 */
    }
    return { report: report(state), warnings }
  }

  async function status({ sessionId }) {
    const state = requireState(sessionId)
    const mr = await gitlab.getMergeRequest({ project: state.binding.projectPath, iid: state.binding.iid })
    const notes = await gitlab.listNotes({ project: state.binding.projectPath, iid: state.binding.iid })
    const result = applySnapshot({ sessionId, mr, notes })
    return { report: report(result.state), state: result.state }
  }

  function review({ sessionId }) {
    const state = requireState(sessionId)
    return { round: state.round, decisions: state.decisions }
  }

  /**
   * 把一次外部快照并入状态；S2 的 watcher 每 tick 调它，S1 的 status 也走它。
   * 新 sha = 新一轮：轮次 +1、重置 await / 停顿计数；同 sha 只刷新解析结果。
   */
  function applySnapshot({ sessionId, mr, notes }) {
    const state = requireState(sessionId)
    const beforeMergeable = state.mergeability?.mergeable === true
    const beforeVerdict = state.round?.review?.verdict ?? null
    let newRound = false

    if (mr.sha !== state.round?.sha) {
      newRound = true
      const observedAt = now()
      const round = { ...buildRound({ mr, notes, cfg: config, observedAt }), n: state.rounds.length + 1 }
      state.round = round
      state.rounds = [...state.rounds, round].slice(-config.ledgerKeepRounds)
      state.stallStreak = 0
      state.reverifyStreak = 0
      state.stallKey = blockingKey(round)
      state.lastProgressAt = observedAt
    } else if (Array.isArray(notes)) {
      state.round = { ...buildRound({ mr, notes, cfg: config, observedAt: state.round.observedAt }), n: state.round.n }
      state.rounds = [...state.rounds.slice(0, -1), state.round]
    }

    state.mr = mr
    state.notesCount = mr.user_notes_count ?? state.notesCount
    state.pipelineStatus = mr.head_pipeline?.status ?? null
    state.mergeability = evaluateMergeable({ mr, round: state.round, decisions: state.decisions })

    const key = blockingKey(state.round)
    if (key === state.stallKey && key !== '') {
      state.stallStreak += 1
    } else {
      state.stallStreak = 0
      state.stallKey = key
    }
    const maxReverify = Math.max(0, ...(state.round?.review?.blocking ?? []).map((item) => item.reverifyCount ?? 0))
    state.reverifyStreak = maxReverify >= 2 ? state.reverifyStreak + 1 : 0

    if (state.mergeability.mergeable && state.mergeableAt === undefined) state.mergeableAt = new Date(now()).toISOString()

    void persist(state).catch(() => {})
    return {
      state,
      newRound,
      reviewArrived: newRound === false && beforeVerdict !== (state.round?.review?.verdict ?? null),
      becameMergeable: beforeMergeable === false && state.mergeability.mergeable === true,
    }
  }

  async function stop({ sessionId, forget = false }) {
    const state = bindings.get(sessionId)
    if (state !== undefined) bindings.delete(sessionId)
    if (forget) {
      if (state !== undefined) await ledger.forget({ projectPath: state.binding.projectPath, iid: state.binding.iid })
      return { stopped: state !== undefined, forgotten: true }
    }
    if (state !== undefined) await persist(state).catch(() => {})
    return { stopped: state !== undefined, forgotten: false }
  }

  function pause({ sessionId, reason }) {
    const state = requireState(sessionId)
    state.paused = { reason, at: new Date(now()).toISOString() }
    void persist(state).catch(() => {})
    return state
  }

  function resume({ sessionId }) {
    const state = requireState(sessionId)
    state.paused = null
    state.lastProgressAt = now()
    return state
  }

  function getState(sessionId) {
    return bindings.get(sessionId) ?? null
  }

  function dispose() {
    bindings.clear()
  }

  return { bind, status, review, applySnapshot, stop, resume, pause, getState, dispose, report, ledger }
}
```

```js
// mr-loop/src/host/tools.js
/**
 * 模型工具面。每个工具：参数校验 → 调 service → 把结果包成 { ok, code, message, data }。
 * 一律不抛异常（模型看到的是结果，不是崩溃），错误码沿用 service 的稳定 code。
 */
const objectSchema = (properties, required = []) => ({
  type: 'object',
  properties,
  ...(required.length === 0 ? {} : { required }),
  additionalProperties: false,
})

const MR_URL = {
  type: 'string',
  description: 'GitLab MR 链接，例如 https://git.htwisdom.cn/group/project/-/merge_requests/240',
}

const ok = (message, data) => ({ ok: true, message, ...(data === undefined ? {} : { data }) })
const fail = (code, message) => ({ ok: false, code, message })
const text = (value) => [{ type: 'text', text: typeof value === 'string' ? value : String(value?.message ?? '') }]

const errorOf = (error) => (typeof error?.code === 'string' ? error.code : 'internal')

/**
 * @param {{ service: object }} deps
 */
export function createTools({ service }) {
  const bind = {
    name: 'mr_bind',
    description: '绑定一个 GitLab MR，立即返回首轮门禁报告。之后由 watcher 在评审出结论时唤醒你，不要用 sleep 轮询。',
    parameters: objectSchema({
      url: MR_URL,
      repo: { type: 'string', description: '可选：仓库根目录（默认用当前会话工作目录）' },
    }, ['url']),
    output: { schema: {}, render: (_args, value) => text(value) },
    async execute(args, exec) {
      const url = typeof args?.url === 'string' ? args.url.trim() : ''
      if (url === '') return fail('invalid-arguments', 'url 必填')
      try {
        const result = await service.bind({
          sessionId: exec?.agent?.session?.id,
          url,
          repoRoot: typeof args?.repo === 'string' ? args.repo : exec?.agent?.session?.header?.cwd,
        })
        const warningText = (result.warnings ?? []).map((item) => `⚠️ ${item.message}`).join('\n')
        return ok(warningText === '' ? result.report : `${result.report}\n\n${warningText}`, { report: result.report, warnings: result.warnings ?? [] })
      } catch (error) {
        return fail(errorOf(error), String(error?.message ?? error))
      }
    },
  }

  const status = {
    name: 'mr_status',
    description: '重新拉取绑定 MR 的当前状态并渲染报告（门禁、轮次、逐条处置、还差什么才能合）。',
    parameters: objectSchema({}),
    output: { schema: {}, render: (_args, value) => text(value) },
    async execute(_args, exec) {
      try {
        const result = await service.status({ sessionId: exec?.agent?.session?.id })
        const state = result.state
        const data = {
          binding: state.binding,
          headSha: state.mr?.sha ?? null,
          round: state.round,
          gates: {
            review: state.round?.review?.verdict ?? null,
            sensitive: state.round?.sensitive?.verdict ?? null,
            mandatory: state.round?.mandatory?.verdict ?? null,
          },
          decisions: state.decisions,
          mergeable: state.mergeability,
          paused: state.paused ?? null,
        }
        return ok(result.report, data)
      } catch (error) {
        return fail(errorOf(error), String(error?.message ?? error))
      }
    },
  }

  const review = {
    name: 'mr_review',
    description: '取当前轮解析好的评审与门禁结构（含每条 FID 的文件、级别、位置、问题、建议、复验次数）。',
    parameters: objectSchema({
      history: { type: 'boolean', description: '可选：附带账本里的历史轮次摘要（默认 false）' },
    }),
    output: { schema: {}, render: (_args, value) => text(value) },
    async execute(args, exec) {
      try {
        const sessionId = exec?.agent?.session?.id
        const { round, decisions } = service.review({ sessionId })
        const data = { round, decisions }
        if (args?.history === true) {
          const state = service.getState(sessionId)
          data.history = (state?.rounds ?? []).map((item) => ({
            n: item.n,
            sha: String(item.sha ?? '').slice(0, 8),
            verdict: item.review?.verdict ?? null,
            sensitive: item.sensitive?.verdict ?? null,
          }))
        }
        return ok(`当前轮 sha ${String(round?.sha ?? '').slice(0, 8)}，阻塞 ${round?.review?.blocking?.length ?? 0} 条`, data)
      } catch (error) {
        return fail(errorOf(error), String(error?.message ?? error))
      }
    },
  }

  return [bind, status, review]
}
```

```js
/** `/mr <url> | status | stop`：命令入口与工具共用同一个 service。 */
const USAGE = '用法：/mr <MR 链接> | /mr status | /mr stop'

export function createCommand({ service }) {
  return {
    name: 'mr',
    description: '绑定一个 GitLab MR 并跟踪它的评审门禁闭环',
    input: { hint: '<MR 链接> | status | stop' },
    async handler({ agent, rawInput }) {
      const input = String(rawInput ?? '').trim()
      const sessionId = agent?.session?.id
      try {
        if (input === '' || input === 'status') {
          const { report } = await service.status({ sessionId })
          return { kind: 'success', text: report }
        }
        if (input === 'stop' || input === 'stop --forget') {

          const result = await service.stop({ sessionId, forget })
          if (!result.stopped) return { kind: 'success', text: '当前会话没有绑定 MR。' }
          return { kind: 'success', text: forget ? '已停止跟踪并删除账本。' : '已停止跟踪该 MR（账本保留）。' }
        }
        if (!/^https?:\/\//i.test(input)) return { kind: 'error', text: USAGE }
        const { report, warnings } = await service.bind({ sessionId, url: input, repoRoot: agent?.session?.header?.cwd })
        const warningText = (warnings ?? []).map((item) => `⚠️ ${item.message}`).join('\n')
        return { kind: 'success', text: warningText === '' ? report : `${report}\n\n${warningText}` }
      } catch (error) {
        return { kind: 'error', text: String(error?.message ?? error) }
      }
    },
  }
```

```js
// mr-loop/src/host/guards.js
/**
 * 进度守卫（设计 §5.7）：只在「没在改善」时停，不看轮数。
 * 触发只返回原因，由调用方 pause + 通知；绑定与账本都保留。
 */
export function evaluateGuards({ state, now, cfg }) {
  if (cfg.maxRounds > 0 && Array.isArray(state.rounds) && state.rounds.length >= cfg.maxRounds) {
    return { reason: 'stalled' }
  }
  if (state.stallStreak >= cfg.stallRounds) return { reason: 'stalled' }
  if (state.reverifyStreak >= cfg.reverifyStreak) return { reason: 'stalled' }
  if (now - state.startedAt >= cfg.wallClockMs) return { reason: 'budget' }
  if (now - state.lastProgressAt >= cfg.idleStopMs) return { reason: 'idle' }
  return null
}
```

```js
// mr-loop/src/host/watcher.js
/**
 * 每会话一个 watcher。节拍：守卫 → 1 个 MR 请求 → 必要时拉 notes → 并快照 → 判断唤醒 → 排下一次。
 * 没有 LLM 调用；所有定时器可注入，单测里用假时钟。
 * 唤醒去抖：同一 (sha, verdict, 门禁摘要) 只唤醒一次，两次唤醒最小间隔 30s。
 */
import { evaluateGuards } from './guards.js'

const WAKE_MIN_GAP_MS = 30000
const TERMINAL_PIPELINE = new Set(['success', 'failed', 'canceled'])

const terminal = (status) => TERMINAL_PIPELINE.has(status)

/**
 * @param {{ cfg: object, gitlab: object, service: object, notify: (input: { sessionId: string, text: string }) => void,
 *           now?: () => number, setTimer?: Function, clearTimer?: Function }} deps
 */
export function createWatcher({ cfg, gitlab, service, notify, now = Date.now, setTimer = setTimeout, clearTimer = clearTimeout }) {
  const timers = new Map()
  const lastWake = new Map()

  function schedule(sessionId, delayMs) {
    clear(sessionId)
    if (!Number.isFinite(delayMs) || delayMs <= 0) return
    timers.set(sessionId, setTimer(() => { void tick(sessionId) }, delayMs))
  }

  function clear(sessionId) {
    const timer = timers.get(sessionId)
    if (timer !== undefined) clearTimer(timer)
    timers.delete(sessionId)
  }

  function wake(sessionId, text) {
    const previous = lastWake.get(sessionId) ?? 0
    if (now() - previous < WAKE_MIN_GAP_MS) return false
    lastWake.set(sessionId, now())
    notify({ sessionId, text })
    return true
  }

  async function tick(sessionId) {
    const state = service.getState(sessionId)
    if (state === null || state === undefined) { clear(sessionId); return }
    if (state.paused !== null && state.paused !== undefined) { clear(sessionId); return }

    const guard = evaluateGuards({ state, now: now(), cfg })
    if (guard !== null) {
      const paused = service.pause({ sessionId, reason: guard.reason })
      wake(sessionId, `已暂停监视（${guard.reason}）。用 /mr resume 继续。`)
      clear(sessionId)
      void paused
      return
    }

    const project = state.binding.projectPath
    const iid = state.binding.iid
    let mr
    try {
      mr = await gitlab.getMergeRequest({ project, iid })
    } catch (error) {
      const code = error?.code ?? 'network'
      if (code === 'unauthorized' || code === 'forbidden' || code === 'no-token') {
        service.pause({ sessionId, reason: 'token' })
        wake(sessionId, `GitLab token 不可用（${code}）。放好 token 后 /mr resume。`)
        clear(sessionId)
        return
      }
      wake(sessionId, `拉取 MR 失败（${code}），${cfg.pollWatchingMs / 1000}s 后重试。`)
      schedule(sessionId, cfg.pollWatchingMs)
      return
    }

    if (mr.state === 'merged' || mr.state === 'closed') {
      wake(sessionId, `MR 已 ${mr.state}，停止监视。`)
      clear(sessionId)
      return
    }

    const pipelineStatus = mr.head_pipeline?.status ?? null
    const hasReview = state.round?.review !== null && state.round?.review !== undefined
    const shouldFetchNotes = hasReview === false
      || mr.sha !== state.round?.sha
      || mr.user_notes_count !== state.notesCount
      || (terminal(pipelineStatus) && pipelineStatus !== state.pipelineStatus)

    let notes
    if (shouldFetchNotes) {
      try {
        notes = await gitlab.listNotes({ project, iid })
      } catch {
        schedule(sessionId, cfg.pollAwaitingMs)
        return
      }
    }

    const result = service.applySnapshot({ sessionId, mr, notes })
    const next = result.state

    const reviewVerdict = next.round?.review?.verdict
    if (reviewVerdict !== undefined && reviewVerdict !== null && (result.newRound || result.reviewArrived)) {
      wake(sessionId, service.report(next))
    } else if (next.mergeability?.mergeable === true && result.becameMergeable) {
      wake(sessionId, `${service.report(next)}\n\n可合并，监视结束。`)
      clear(sessionId)
      return
    }

    const delay = !terminal(pipelineStatus)
      ? (pipelineStatus === null ? cfg.pollNoPipelineMs : cfg.pollAwaitingMs)
      : cfg.pollSettleMs
    schedule(sessionId, delay)
  }

  return {
    tick,
    start(sessionId) { schedule(sessionId, cfg.pollAwaitingMs) },
    stop(sessionId) { clear(sessionId) },
    stopAll() { for (const sessionId of [...timers.keys()]) clear(sessionId) },
    isWatching(sessionId) { return timers.has(sessionId) },
  }
}
```
